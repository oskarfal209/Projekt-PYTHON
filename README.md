# Projekt-PYTHON

Zaprezentowany przez nas projekt w języku Python z pomocą biblioteki graficznej Tkinter to IT clicker.
Gracz klika przycisk, za pomocą którego wykonują się różne informatyczno-programistyczne czynności.
Gracz zyskuje kolejnymi kliknięciami BTC, za którego może kupić ulepszenia: Programistę z Salezjan, Montera White, Gemini Pro oraz Generała Es.
Ulepszenia dodają m.in. szybsze samoistne przychody BTC, wielokrotność pobieranego BTC za kliknięcie.
